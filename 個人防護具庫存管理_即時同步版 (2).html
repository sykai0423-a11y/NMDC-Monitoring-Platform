🔗 即時同步說明
點擊右上角「連結 Excel」後選取本機的 xlsx 檔案，系統會立即讀入現有庫存， 且之後每次進貨 / 領取都會在 2 秒內自動寫回該 Excel，不需要手動按任何按鈕。
⚠️ 此功能需要 Chrome 86+ 或 Edge 86+（File System Access API）。Firefox / Safari 請改用下方「備份下載」。
⚠️ 你的瀏覽器不支援 File System Access API，無法即時寫回本機 Excel。請改用下方「備份下載」功能。
